## 2. 有效线性闭合（`results/p3/closure_coefficients.json`）

模型：
`dqdt + c_J J + c_mu(μq) + c_nu(-ν∇²q) + c_beta(β∂xψ) + c_h4(-∇⁴q) - c_F F = 0`

训练 run 0–399，验证 run 400–479；每 run 5 对，t∈101..194。

| case | c_J | c_mu | c_nu | c_beta | c_h4 | c_F | val ratio baseline→fit |
|---|---:|---:|---:|---:|---:|---:|---:|
| eddy1000 | 1.09 | 0.91 | 2.03 | — | 0.00 | 1.07 | 0.276 → 0.260 |
| eddy10000 | 0.99 | 0.82 | 8.48 | — | 0.00 | 0.97 | 0.523 → 0.522 |
| jet1000 | 0.90 | 1.10 | 1.41 | 2.78 | 0.00 | 1.11 | 0.565 → 0.380 |

- **jet**：线性闭合把残差降 **33%**，有效 β=2.78 与 oracle 一致。
- **eddy10000**：几乎无改善（0.523→0.522）；双调和超黏系数为 0。
  说明缺失项不在 `J/μq/∇²q/∇⁴q/β/F` 的张成空间里（更可能是滤波/时间离散/尺度依赖通量）。
- **eddy1000**：残差本来就小，闭合收益有限（0.276→0.260）。

## 3. 对 PC-DPS 的含义

- eddy10000 上 PC-DPS 最好 -7.7%，但线性闭合无法降低其残差；物理项只能提供
  部分大尺度/缺口约束（诊断：k0–8 0.378→0.358，gap 0.394→0.378），
  细尺度 k9–32 仍≈1.0。
- jet full 上物理项基本无效，与 jet 残差大、且数据项主导一致。
- 三帧中心差分、逐样本归一化、残差低通、x0 低通、t_min/t_max 门控都没有超过 7.7%；
  这些负结果保留在 `/tmp` 与日志中，正式结果仍报告 7.7%。

## 4. 结论与后续

1. 64×64 滤波场的 QG 残差不能严格闭合；有效线性闭合只在 jet 上显著（-33%），
   在 eddy10000 上无效。
2. PC-DPS 的 7.7% 是“软约束 + 部分尺度”的真实上限；要过 8% 需要
   **尺度依赖闭合**（ν_eff(k)）或**学习型亚格子模型**，而不是继续调 λ。
3. 报告应明确：物理项是软约束；eddy10000 的残差不可线性闭合；PC-DPS 未达 8% Gate。
